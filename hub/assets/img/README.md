# Illustrationen

Ausschließlich eigene Illustrationen der Lehrkraft. **Keine** Buchseiten, Screenshots oder Lehrwerksabbildungen.

- Dateinamen: `G0.webp` … `G8.webp`, `W1.webp` … `W3.webp` (optional `hero.webp`)
- Format: WebP, Seitenverhältnis 3:2 (z. B. 1200 × 800), höchstens 200 KB
- Alt-Text je Station in `hub/config.json` → `stations[].alt` (leer = automatischer Text aus Ort und Thema)
- Fehlt ein Bild, zeigt die Map eine Platzhalter-Postkarte.

Die PNG-Originale bitte **nicht** hier ablegen (`.gitignore` blockt sie). Die Konvertierung übernimmt Claude, sobald die Dateien da sind.
